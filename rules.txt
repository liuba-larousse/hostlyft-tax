# ============================================================================
#  Expense categories - edit this file, not the code
# ============================================================================
#
#  HOW IT WORKS
#      One rule per line:
#
#          category = word, another word, a phrase
#
#      If any of those words appears in an expense's vendor or description,
#      it gets that category. Matching ignores capitals and accents.
#
#      Rules are tried top to bottom, so put the specific ones first.
#      Lines starting with # are notes and are ignored.
#
#  WHAT HAPPENS TO ANYTHING THAT MATCHES NOTHING
#      It stays "uncategorized" and is listed after every run. Nothing is
#      ever guessed into a category - a wrong category is a wrong deduction,
#      and it would be invisible.
#
#  CONTRACTORS ARE NOT LISTED HERE
#      They are matched by name, nickname and payment alias in
#      taxlib/config.py, which also knows who needs a W-9 and who needs a
#      W-8BEN. Adding them here would split that in two places.
#
#  THE SCHEDULE C COLUMN
#      The bracketed line number is where that category goes on Schedule C.
#      It is a starting point for filing, not advice.

# NOTE: this block sits ABOVE travel deliberately. Rules are tried
# top to bottom, and the travel rule matches the bare word "Uber" -
# so with travel first, "UBER *EATS" would be deducted as a taxi.
# --- business meals ------------------------------- [Schedule C line 24b] --
# ONLY 50% OF THESE IS DEDUCTIBLE. The temporary 100% allowance for
# restaurant meals ran in 2021-2022 only and has expired. The halving is
# applied by the tax calculator, not here - this file only decides the
# category. See CATEGORY_DEDUCTIBLE_SHARE in taxlib/config.py.
#
# A MEAL NEEDS A BUSINESS REASON, AND THE BANK CANNOT SEE ONE.
# A card row says "restaurant". It cannot say who was there or why, and
# the IRS asks for both. So a row landing here is CATEGORISED, not yet
# proven: confirm the business purpose and who was present with
#     python scripts/meals.py
# Anything unconfirmed is left out of the deduction and listed.
#
# Lunch on your own near home is a personal living expense, not a business
# meal, however much you were thinking about work at the time.
meals = restaurant, brasserie, bistro, boulangerie, cafe, café, coffee,
        traiteur, pizzeria, trattoria, osteria, sushi, kebab, burger,
        McDonald, Starbucks, Pret A Manger, Deliveroo, Uber Eats,
        UBER *EATS, Just Eat, Glovo, DoorDash, catering

# --- equipment ----------------------------------- [Schedule C line 18] ----
# ALWAYS FLAGGED, NEVER ASSUMED. She asked for equipment to be read from
# the personal account, and asked to be shown each one rather than have it
# counted automatically - which is right, because Amazon sells groceries as
# readily as laptops and the bank row cannot tell them apart.
#
# TWO THINGS DECIDE WHAT IT IS WORTH, AND NEITHER IS ON THE STATEMENT:
#   - the BUSINESS-USE PERCENTAGE. A laptop used partly personally is
#     deductible only at that share. Never assume 100%.
#   - the PRICE. Under $2,500 an item, the de minimis safe harbour expenses
#     it in the year you bought it. Above that it needs a Section 179
#     election on Form 4562, or it is depreciated over several years.
equipment = laptop, macbook, notebook computer, Apple Store, Amazon Eu Sarl,
            Dell, Lenovo, monitor, keyboard, docking station, hard drive,
            iPhone, headset, webcam, printer

# --- entertainment ------------------------ [NOT DEDUCTIBLE AT ALL] --------
# ZERO PERCENT. Not a lower rate - no deduction.
#
# The 2017 Act removed the entertainment deduction outright. Before it,
# entertainment was 50% like meals, which is why plenty of advice still
# says so. It is wrong for 2026.
#
# This block sits ABOVE travel and BELOW meals on purpose. A concert or a
# match is not travel; a restaurant is still a meal at 50%.
#
# THE SPLIT-BILL RULE: food and drink AT an entertainment event stay 50%
# deductible only if they are billed separately, or shown separately on the
# same bill. Billed as one lump with the tickets, the whole lot is
# disallowed. Ask for a separate receipt at the time - it cannot be fixed
# afterwards.
entertainment = theatre, theater, cinema, concert, nightclub, golf,
                stadium, ticketmaster, eventbrite, sporting event,
                country club, yacht

# --- money given back to clients --------------- [Schedule C line 2] -----
# Refunds reduce what you actually earned. On Schedule C these are
# "returns and allowances", taken off gross receipts rather than added to
# expenses - the category is kept separate here so it can be reported that
# way at filing time.
# Deliberately NOT the bare word "refund". Money coming back FROM a vendor
# is not a return or allowance - it makes that purchase cost less, and
# belongs in the purchase's own category. Only money given back to a CLIENT
# belongs on line 2.
refunds to clients = Refund of, partial refund of, credit note, chargeback

# --- money coming back ------------------------- [reduces the expense] ---
# Cashback is a rebate on spending, not income. It reduces what the
# purchases cost rather than adding to what was earned - which is why these
# rows carry a NEGATIVE amount.
cashback and rebates = cash back reward, cashback, rewards credit
