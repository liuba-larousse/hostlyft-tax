# ============================================================================
#  Expense categories - edit this file, not the code
# ============================================================================
#
#  HOW IT WORKS
#      One rule per line:
#
#          category = word, another word, a phrase
#
#      If any of those words appears in an expense's vendor or description,
#      it gets that category. Matching ignores capitals and accents.
#
#      Rules are tried top to bottom, so put the specific ones first.
#      Lines starting with # are notes and are ignored.
#
#  WHAT HAPPENS TO ANYTHING THAT MATCHES NOTHING
#      It stays "uncategorized" and is listed after every run. Nothing is
#      ever guessed into a category - a wrong category is a wrong deduction,
#      and it would be invisible.
#
#  CONTRACTORS ARE NOT LISTED HERE
#      They are matched by name, nickname and payment alias in
#      taxlib/config.py, which also knows who needs a W-9 and who needs a
#      W-8BEN. Adding them here would split that in two places.
#
#  THE SCHEDULE C COLUMN
#      The bracketed line number is where that category goes on Schedule C.
#      It is a starting point for filing, not advice.
